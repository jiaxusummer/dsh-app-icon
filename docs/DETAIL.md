# 应用图标

换 **DeepSeek Harness 桌面版**的窗口、任务栏、开始菜单和托盘图标：换回默认，或者用你自己传的图。

入口：**设置 → 应用图标**。

## 怎么用

1. 打开 **设置 → 应用图标**。最上面是 **换图标**（传自己的图）。
2. 下面是 **当前图标**（含当前图标和历史图标）和 **默认图标**，左右 7:3 并排。
3. 用哪边就点哪边；想换回上一次的，点 **换回历史头像**。
4. 确认框会说清楚：**DSH 要退出一次**。
5. 从右下角托盘图标右键 →「退出」。
   - 关窗口不算，它只是躲进托盘；进程要退干净。
6. 后台趁 DSH 关着改 exe、换 `resources\icon.png` 和 `tray.ico`，然后自动把 DSH 打开。
7. 任务栏/开始菜单还咬着旧图时，面板里「刷新 Windows 图标缓存」；再不行注销一次 Windows。

传图：PNG / JPEG / WebP，最多 12 MB。选完可以在卡片里拖动、缩放，方框里就是最后的样子；点「用这一块」才生成 16/20/24/32/40/48/64/96/128/256 一整套，再走同样的退出/重开流程。

## 三块

- **换图标**：传图、预览，然后应用。
- **当前图标**：从 exe 里把当前图标抠出来做预览，并和内置的默认图标逐张比对。不是默认图标时不额外标注，预览仍然是当前真实的样子。下面还有 **历史图标**——每次换之前，插件都会把旧图标存进 `backups\icons\`，点 **换回历史头像** 就能换回去。
- **默认图标**：DeepSeek Harness 原本的图标；DSH 升级后也会回到这个。

「细节和应急」默认展开：换完图标记得点 **刷新 Windows 图标缓存**，任务栏/开始菜单才不会咬着旧图；「顺带重启资源管理器」默认勾选（任务栏会闪一下，开的文件夹会关）。

## 它到底改了什么

| 位置 | 作用 |
| --- | --- |
| `DeepSeek Harness.exe` 的 `RT_ICON` / `RT_GROUP_ICON`（组 id 1、语言 1033） | 任务栏、开始菜单、窗口、Alt+Tab 的脸 |
| `resources\tray.ico` | 右下角托盘的脸 |
| `resources\icon.png` | 一部分窗口/壳层场景的脸 |

exe 是用 Win32 的 `BeginUpdateResource` / `UpdateResource` / `EndUpdateResource` 原地改的，不换文件、不重装。

每次改之前会：

- 把 exe 里现有的整套图标抠成 `current.ico`（小备份，保留最近几份）；
- 复制一份整只 exe 到数据目录的 `backup\exe-last-good.exe`（约 246 MB，防手滑；可以在细节里删）；
- 打完立刻核对：**group 里的条目数 = 新图标的条目数**，且**每一张图的字节都和源文件一模一样**，多出来的旧 `RT_ICON` 会被删掉；
- 任何一步对不上就不换 resources，并整只还原；
- 重开 DSH 后 60 秒没起来，也会整只还原再拉起来。

数据目录：`%DSH_HOME%\dsh-app-icon`（一般是 `C:\Users\<你>\.dsh\dsh-app-icon` 或 DSH 自己的 home），日志在 `logs\`。

## 踩过的坑

1. **运行中的 exe 改不了。** 这是流程必须退出一次的原因。DSH 桌面版没有给插件「退出整个应用」的 API，所以只能你自己从托盘退出；后台会一直等你（默认等 1 小时）。
2. **不是「必须 10 个尺寸」。** 实测拆开的两只 exe：官方 0.2.2 的 exe 里是 **7 个**（16/24/32/48/64/128/256），另一套自制图标是 **10 个**。两套都能正常打进去，也都能被 Windows 显示。旧脚本把门槛写死成 10，才会把 7 个那次的成功补丁误判成失败。真正要守的规矩是：**打完 group 的条目数要和源 .ico 对得上，引用的每张图字节也要对得上**。这个插件每次做完都会逐张比对。
3. **PNG 压缩的小尺寸也能用。** 官方 exe 从 16 到 256 全是 PNG 压缩，Win11 的 Explorer 照样显示；插件自己生成的自定义图一律输出 DIB（兼容面最宽），默认图标原样保留。
4. **桌面别放 .cmd 启动器。** 中文路径会被 cmd 读坏（老脚本踩过）。插件里所有路径都走 JSON 文件传，不经过命令行拼接。
5. **换完签名就失效**（原来有杭州求索的有效签名，资源一改哈希就对不上），会显示「未知发布者」。不影响运行。
6. **DSH 自动更新会把官方 exe 拉回来。** 更新完图标变回官方是正常的，再换一次即可。
7. **任务栏/开始菜单可能咬着旧图。** 先「刷新图标缓存」，再不行重启资源管理器或注销。插件里的「刷新缓存」会跑 `ie4uinit -show`；勾上「顺带重启资源管理器」会杀掉 explorer 并重启它（任务栏闪一下，文件夹窗口会关）。
8. **换完要确认 exe 真的起来了。** 后台会等新进程；没起来就整只还原，不会留一个打不开的 DSH。

## 限制

- **只在 Windows 桌面版**（`process.execPath` 是 `DeepSeek Harness.exe`）可用。`dsh web` / 源码跑的是 `node.exe`，面板会说明不支持。
- **必须退出一次 DSH**，插件替不了这一步。
- 托盘里找不到图标时，去 `↑`（隐藏的图标）里找；窗口关了只是隐藏，不算退出。
- DSH 每次自动更新后，图标会回到官方，需要再换一次。
- 传图依赖 DSH 自带的 `sharp`；如果某个版本没带，会明确报「生成不了」，默认图标不受影响。

## 维护备注（以后再改这个插件时）

- 后台不是直接 `spawn('powershell.exe', ...)`：Node 的 `detached: true` 在 Windows 会带 `DETACHED_PROCESS`，powershell 拿不到控制台，秒退（exit 0，日志都不写）。现在的做法是写一个 UTF-16LE 的 `launch.vbs`，用 `wscript` 当跳板，VBS 里 `sh.Run "... powershell.exe ...", 0, False` 以隐藏窗口拉起。wscript 是 GUI 进程、没有控制台，powershell 才能活得比 DSH 久。
- `assets/helper/apply.ps1` 必须存成 **UTF-8 with BOM**。PowerShell 5.1 读无 BOM 的 .ps1 会按 GBK 解，中文注释/字符串一乱，整个脚本直接解析失败（报“缺少 }”之类），而且退出码是 1、什么都不写。改完用 Parser 验一遍。
- 判断“现在用的是哪套”靠的是 exe 图标逐张 SHA-256 对比，不是文件时间或配置。DSH 升级换 exe 后会自动不在内置的几套里，这是对的。
- 排版/字号/按钮状态/特别告知的规则见 [LAYOUT.md](LAYOUT.md)；世界归档在 `G:\DSH-home\worlds\default\room\爸爸的工作室\dsh-app-icon_排版规则.md`。

## 应急

- 面板里「细节和应急」→ 看后台日志，每一步都有时间。
- 手动还原：把 `%DSH_HOME%\dsh-app-icon\backup\exe-last-good.exe` 覆盖回 `DeepSeek Harness.exe`，再把最近一份 `backups\icons\<时间>\` 里的 `icon.png`、`tray.ico` 拷回 `resources\`。
- 默认图标来自 DeepSeek Harness 官方安装包，仅用于还原官方外观；版权归 DeepSeek。插件自己的图标是另画的。
