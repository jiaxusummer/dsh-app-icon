# dsh-app-icon 排版规则（插件内源文件）

> 归档日期：2026-11-14 · 插件版本 0.1.0
> 插件内源文件：本文件
> 世界归档：`G:\DSH-home\worlds\default\room\爸爸的工作室\dsh-app-icon_排版规则.md`
> 改规则先改 `client.js` 和本文件，再同步世界归档。

适用：**设置 → 应用图标** 这一页。下面所有“px”都是 CSS 像素。

## 1. 字体与字号

| 类型 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 插件标题 / 卡片标题 / 自定义图标名 / 弹窗标题 | **15px** | 600 | 主文字色 |
| 卡片功能介绍 | **12px** | 400 | 二级文字色 + `opacity:.88`（灰，不用纯白） |
| 特别告知 | **12px** | 600 | warning 黄（`--dsw-alias-state-warn-primary`） |
| 按钮 | **11px** | 400 | 主文字色 |
| 细节键值行 | **12px** | 400 | 键名灰，值主色 |

- 全插件字体统一：`"Microsoft YaHei","微软雅黑","PingFang SC","Segoe UI",sans-serif`。
- CSS 变量：`--dx-title-size:15px`、`--dx-desc-size:12px`。
- 所有“特别告知/重要提醒”一律加 `.dx-notice`，不要再手写黄色和字号。
- 说明文字一律用 `.dx-desc`，保持 12px 灰色，不混用纯白。

## 2. 卡片通用规则

- 页面：最大宽 780px，卡片之间竖向间距 **12px**。
- 卡片：背景 `bg-layer-1`，1px 边框 `border-l1`，圆角 12px，内边距 **8px**。
- 卡片与卡片之间 **12px**；卡片内边距 **8px**；标题、功能按钮离卡片上/左/右边框 **8px**。
- 卡片标题在左，功能按钮在右，**同一行**；不要按钮单独占一行。
- 左右两列比例 **7:3**，两张卡**等高**（`align-items:stretch`）。
- 卡片内不再套卡片；分区只做分隔线，不做第二层背景框。

## 3. 顶部「换图标」卡片

- 第一行：左「换图标」，右「选一张图…」；按钮离上、右边框 8px。
- 说明文字在标题行下面，间距 6px。
- 默认状态只有“标题行 + 说明”这么高，不再单独占一行放按钮。
- 选图后预览、裁图区在下面展开；右上角按钮始终保留。
- 「选一张图…」是 `label` 包 `file input`，样式和普通按钮共用 `.dx-btn`。

## 4. 左右两列

- `.dx-two`：`display:flex; gap:12px; align-items:stretch`。
- 左卡 `flex:7 1 0; min-width:0; padding:0`。
- 右卡 `flex:3 1 0; min-width:0; padding:8px`。

### 左卡（当前图标 / 历史图标）

- 整张卡**上下等分**，中间一条 **1px 虚线**（`.dx-split`），不是嵌套卡片。
- 每一半结构相同：
  - 顶部一行：标题在左，按钮在右（当前图标 + 重新检测；历史图标 + 换回历史头像）；
  - 下面一行：**48×48** 图标 + 右侧说明文字。
- 图标规则（三处一致）：
  - 尺寸 **48×48**；
  - 离卡片左边框 **8px**；
  - 图标顶部到各自区域顶部：8px 内边距 + 标题行（约 27px）+ 6px 间距，三处用同一公式；
  - 当前、历史、默认三处必须同尺寸、同左边距、同顶部距离。

### 右卡（默认图标）

- 顶部一行：默认图标 + 换回默认。
- 下面 48×48 图标；图标顶部同样 39px。
- 说明在图标下方；最后一行提示贴底（`margin-top:auto`）。

## 5. 文案格式

三组说明都短，优先一行，统一用 ` · ` 分隔：

- 当前图标：`N 个尺寸 · 托盘/窗口已对齐`（没对齐时：`托盘/窗口未对齐`）。
- 历史图标：`暂无历史 · 换过一次后会有`；有历史时：`存于 11-14 03:15`。
- 默认图标：`N 个尺寸 · 官方原版`；底部提示：`换回后三处一起恢复`（三处 = 窗口 / 任务栏 / 托盘）。

不要再用这些长句：

- 「exe 里 10 个尺寸」
- 「DSH 原本的小鲸鱼」
- 「7 个尺寸 · 16–256」
- 「窗口、任务栏、托盘一起变回官方。」

## 6. 按钮

- 能按：**实线描边**、透明底、11px、内边距 4/9、圆角 9；hover 用 `bg-layer-2`。
- 不能按/禁用：**虚线边框** + 二级文字色 + `opacity:.65` + `pointer-events:none`。
- 主面板不用白色实心按钮；白色主按钮只保留在确认弹窗的主操作（「知道了，去退出」）。
- 文件选择 `label`、取消、换成这个、用这一块，全部复用同一套 `.dx-btn`。

## 7. 细节和应急

- 标题「细节和应急」15px / 600；卡片内边距 8px，和其它卡一致。
- 键值行 12px；键名灰色，值白色。
- 普通说明 12px 灰色（`.dx-desc`）。
- 「换完图标记得刷新 Windows 图标缓存」这类提醒用 `.dx-notice`（12/600/黄）。
- 刷新缓存按钮 11px；勾选项文字 12px 灰色。
- 默认展开。

## 8. CSS 类速查

| 类 | 用途 |
|---|---|
| `.dx` | 页面容器；字体、标题/说明字号变量、12px 间距 |
| `.dx-title` | 插件标题 15/600 |
| `.dx-strong` | 卡片标题 15/600 |
| `.dx-name` | 自定义图标名 15/600 |
| `.dx-desc` | 卡片说明 12px 灰 |
| `.dx-notice` | 特别告知 12/600 黄 |
| `.dx-card` | 卡片底/边框/圆角/内边距 |
| `.dx-two` | 左右 7:3 两列，等高 |
| `.dx-pane-left` / `.dx-pane-right` | 左右卡宽度与内边距 |
| `.dx-half` | 左卡上下半区 |
| `.dx-split` | 上下半区之间的虚线 |
| `.dx-half-head` | 标题 + 功能按钮一行 |
| `.dx-icon-box` | 三处 48×48 图标 |
| `.dx-btn` | 按钮/文件选择统一外观 |
| `.dx-btn:disabled` / `.is-disabled` | 禁用虚线灰 |
| `.dx-details` | 细节和应急卡片 |

## 9. 踩过的坑（不要再犯）

- 不要硬排两列导致左卡内容撑出去盖住右卡；必须 `min-width:0`，用 flex 定比例。
- 不要在历史区里再套一层卡片。
- 不要让左右卡高度不等、底部留大空；用 `align-items:stretch` 让右卡跟左卡等高。
- 不要把顶部卡片的「选一张图…」放在标题下面单独一行。
- 不要在主面板混用白色实心、实线描边、虚线三种按钮状态。
- 不要用纯白写说明；说明统一 12px 灰。
- 不要把三个图标做成不同大小或不同边距。
- 不要混用标题字号；所有标题 15px / 600。
- 不要把“特别告知”写成普通灰字；统一 `.dx-notice` 黄色。
